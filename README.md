# Imam Getsiev Portfolio

Premium one-page portfolio website for Imam Getsiev, a professional Grappling, Wrestling and Brazilian Jiu-Jitsu coach based in Sharjah, UAE.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- `next/image`

## Commands

```bash
npm install
npm run dev
npm run build
npm run typecheck
```

## Content

Editable content lives in `lib/content.ts`.

Image paths are centralized in `lib/images.ts`.
